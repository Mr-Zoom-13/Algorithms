## Запуск решения

Для репозитория не нужны сторонние библиотеки. Установите Python 3.10 или новее и запустите нужный файл:

```powershell
python ".\Лекция 3 Бинарный поиск\easy\1.py"
```

Данные передаются через стандартный ввод. Например:

```text
2 3 10
```

Результат программа выводит в консоль. Формат ввода и вывода зависит от исходного условия, ссылка на которое обычно находится в первой строке файла.

## Что реализовано

- сортировка слиянием и другие алгоритмы сортировки;
- собственная реализация двоичной кучи;
- стеки, очереди и деки;
- классический бинарный поиск;
- бинарный поиск по ответу;
- префиксные суммы и разностные массивы;
- корневая декомпозиция;
- деревья отрезков;
- слияние отсортированных последовательностей;
- задачи на два указателя и скользящее окно.

## Проверка кода

При каждом обновлении репозитория GitHub Actions компилирует все Python-файлы и обнаруживает синтаксические ошибки:

```powershell
python -m compileall -q .
```

Это учебные решения для конкретных систем тестирования. Проверка синтаксиса не заменяет тесты из исходных задач.

## Структура решения

Большинство файлов намеренно остаются самостоятельными скриптами:

```python
# ссылка на условие

# чтение входных данных
# реализация алгоритма
# вывод ответа
```

Такой формат позволяет скопировать решение в проверяющую систему без дополнительной настройки проекта.
